# Credits

## Inspirations
BobbinLoom was inspired by:
- **SillyTavern** — LLM frontend for power users (Cohee, RossAscends) — AGPL-3.0 — https://github.com/SillyTavern/SillyTavern
- **Marinara Engine** — AI frontend (Pasta-Devs) — AGPL-3.0 — https://github.com/Pasta-Devs/Marinara-Engine

## Format compatibility
BobbinLoom imports and exports:
- **Character Card Spec V2** — the community character card format
- **SillyTavern-compatible World Info / lorebooks**

Lorebook support is a clean-room implementation written against the format's data structure; no code is derived from SillyTavern or Marinara Engine. Their names are used nominatively to describe compatibility.
